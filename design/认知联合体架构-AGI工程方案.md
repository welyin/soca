# 认知联合体架构（Society-of-Cognition Architecture, SoCA）
## 一套"架构优先、闭环优先、群体优先"的可工程化 AGI 方案

> 设计来源：本文档严格遵循讨论中形成的九条公理——①架构先于规模；②三层嵌套组织原则（协作层"按需共享"、进化层"达尔文竞争"、全局层"轻量集中与抑制"）；③分布式认知 + 集中收敛的双模块，中间以接口总线耦合；④接口四要件（上行保真、显式回应、再感知闭环、模块不越界）；⑤分层记忆与主动遗忘、非对称记忆；⑥具身闭环、预测误差驱动、内在动机；⑦由"闭环完整的小主体"组成社会，任务导向临时集结、完事即散；⑧确定性抑制层兜底，概率结论不得凌驾硬约束；⑨知识在硅基可零成本共享的"文化层"。

---

## 0. 一句话总纲

**先做一个哪怕很小、但"感知—认知—决策—行动—再感知"闭环完整的主体（数字苍蝇），再在同一架构上拧大规模旋钮，最后让大量这样的完整主体组成社会。** 智能来自组织方式，参数与知识只是填充物。

## 1. 总体分层

```
┌─────────────────────────────────────────────────────────────────┐
│ L7 主体社会与文化层  多 Agent（每个都是完整内核）/ 临时组队 / 知识公地 / 社会级抑制 │
├─────────────────────────────────────────────────────────────────┤
│ L6 动机与目标层      宪法价值(不可学) / 目标栈 / 好奇心内在动机 / 人类在环否决     │
├─────────────────────────────────────────────────────────────────┤
│ L4 全局执行层        执行仲裁(只收敛不定事实) │ 确定性抑制(宪法/刹车) │ 代谢调度   │
│ L3 达尔文竞争层      多候选变异 → 红队批评/工具核验 → 选择 → 修剪(睡眠遗忘)       │
│ L2 全局工作空间      黑板/公共广场：结构化门槛、反方强制、来源标注、有限容量广播    │
│ L1 感知与世界模型    异构专门认知单元(并行/稀疏激活) + 预测与误差(双系统)         │
├─────────────────────────────────────────────────────────────────┤
│ L0 具身/环境总线     感知-行动统一接口、append-only 原始事件流（上行保真）         │
└─────────────────────────────────────────────────────────────────┘
            ▲ 横切：L5 分层记忆（工作/情景/语义/规范，各带半衰期）
            ▲ 横切：全链路审计 trace、版本化可回滚、持续评估 harness
```

认知流是一个闭环（可多圈迭代，圈数=System2 深度）：

> 感知 → 专门单元并行出假设 + 世界模型算预测误差 → 上黑板（结构化校验/强制反方/标来源）→ 注意聚焦并全局广播 → 代谢层按难度发预算 → 达尔文层生成候选种群并批评选择 → 执行仲裁收敛 → **确定性抑制层刹车** → 作用于环境 → 观察结果、误差回灌、更新世界模型与记忆 →（睡眠期）巩固与遗忘。

## 2. 各层职责与工程实现

### L0 具身/环境总线（Embodiment Bus）
- **职责**：统一 sensor/actuator 适配；所有原始观测进入 **append-only 事件流**，带时间戳、来源、置信度。决策层无权改写原始流（接口要件"上行保真"）。
- **工程**：消息总线（开发期内存 channel；生产期 NATS/Kafka）；统一 `Observation/Action` schema（可直接复用 Gymnasium 环境接口或 MCP tool 描述）。
- **现成**：MCP、OpenAI tool schema、各类 env 接口。

### L1 感知与世界模型（分布式认知器官）
- **职责**：一组**异构、并行、可插拔**的 specialist（语言/数值/时序/因果/风险/效价……），可由小 LM、编码器、经典算法、检索器混合（神经-符号）。**世界模型**输出预测与预测误差 surprise，误差是全系统驱动力（主动推断/自由能原理）；快模型(System1)与慢模型(System2)分层。
- **稀疏激活**：gating 按情境只召唤相关 specialist（MoE 式），不全员运行。
- **工程**：统一 `trait Specialist`；gating 用规则+小判别器；世界模型用 SSM / 粒子滤波(POMDP) / LLM 维护结构化 belief state。主动推断可直接用 `pymdp` 等现成库验证。

### L2 全局工作空间 / 黑板（架构心脏 = "公共议题平台"）
- **职责（对应全局工作空间理论 GWT 与经典 blackboard 架构）**：
  - **表达零门槛、上正式队列高门槛**：原始信号自由进；要进入全局注意，候选必须通过"提案编译器"校验——证据、不确定性、**强制反方意见**、来源/利益标注、影响范围齐全，否则打回补全。
  - **有限容量点火广播（ignition）**：按显著度 `salience = 不确定性 × 价值 × 时效 × 新颖度` 选出少数焦点，fan-out 广播给全部模块，使全系统围绕同一焦点协同（意识的串行瓶颈是**故意的**）。
  - **反谄媚/防极化**：append-only、不可被执行层删改；内置 devil's-advocate 专门单元，必须生成对立假设。
- **工程**：event-sourced 黑板（状态+不可变事件日志）；pub-sub 广播；schema 校验器。

### L3 达尔文竞争层（变异—选择—淘汰 = 内部进化）
- **职责**：对焦点问题**并行生成候选种群**（多 agent/多采样/多立场/多温度）→ critic 互相质证、**可验证项一律用工具/代码/检索核验**（事实核验优先于流畅度）→ 选择融合（best-of-N / self-consistency / 辩论 / process-reward / 贝叶斯更新）→ 落选者从工作记忆清除，提炼出的教训入长期记忆。
- **睡眠机制**：离线 job 做重放、去重、合并、修剪（对应突触稳态与"遗忘是机制"）。
- **self-play**：无标准答案的领域靠红蓝对抗、open-ended 进化持续造多样性。
- **工程**：async worker 池；候选为不可变消息；critic 与生成器**不同源**（禁止自评）；选择算法可插拔；睡眠=定时 consolidate 任务。

### L4 全局执行层（轻量集中：收敛、抑制、供血）
- **执行仲裁 Executive**：只在 L3 结果上聚焦、权衡、定动作、定责，**不自行生产事实**（事实只来自 L0–L3）。
- **确定性抑制 Inhibition（=抑制性神经元/法治，最关键的安全件）**：硬约束以**确定性规则引擎 + 独立审核模型**实现，对输出有一票否决，优先级高于一切概率结论；**不可被训练/RLHF 覆盖**（神经-符号双轨）。防"失控同步"（对应癫痫/群体狂热）。
- **代谢调度 Metabolism（=神经血管按需供血）**：统一 token/时间/成本预算，按难度与利害动态分配——简单问题走快通道，难问题唤醒 System2、扩大种群、加深迭代（adaptive test-time compute）。
- **元认知**：评估"我是否确定、是否需要更多信息/工具"，触发再感知（议题 A→B→C 式追问）。
- **工程**：Executive=状态机/规划器（LLM 出推理，确定性 policy checker 放行）；预算控制器；guardrails 用规则引擎（如因果决策表/形式化策略）+ 独立模型。

### L5 分层记忆（横切，主动遗忘，非对称）
| 记忆层 | 内容 | 半衰期 | 工程载体 |
|---|---|---|---|
| 工作记忆 | 当前黑板 | 极短，任务结束清空 | KV / 上下文窗口 |
| 情景记忆 | 具体经历 | 时间衰减 | 向量库 + 时间索引 |
| 语义/程序记忆 | 抽象知识与技能 | 慢、巩固而来 | 图库 / 知识库 / 固化技能 |
| 规范记忆 | 宪法、身份核心、**自身决策审计** | **不可遗忘、不可篡改** | 规则库 + append-only 审计 |

- **非对称原则**：对"自身行为/权力输出"长记忆以便问责；对"外部临时实体/原始个人数据"短记忆、最小化、可修复。
- **巩固管线**：睡眠期把情景压缩为语义（压缩=有原则地遗忘），去重、过时降权、unlearning；遗忘=TTL/合并/冷归档（法定/审计可受控恢复），不是物理销毁。
- 每条记忆带 TTL、来源、可信度、访问计数。

### L6 动机与目标层
- **内在动机**：以"信息增益/预测误差下降"为好奇心驱动，主动选择最能降低不确定性的探索动作。
- **目标栈**：宪法价值（不可学、不可改）→ 持久目标 → 临时任务（完成即销，事务性）。
- **对齐边界**：RLHF/偏好只调"风格与手段"，不得改写顶层宪法；高风险动作 human-in-the-loop 保留最终否决（意志与责任不交给概率系统）。

### L7 多主体社会与文化层
- 上述整套是**一个完整小主体内核**；社会由若干内核构成，**每个都是闭环主体，不是无主体的函数调用**。
- **临时组队**：按任务招标、自由集结、任务结束即解散、无固定等级（事务性组织/自由人联合体）。
- **协作协议=文化层**：标准化能力声明、任务招标、证据交换（可直接用 MCP/ACL 类协议）；**知识公地**：技能与经验在硅基可零成本复制共享（碳基脑做不到的"知识公有制"）。
- **社会级抑制**：保留异见主体、限同质化、防级联(cascade)与群体极化；声誉/信用带半衰期、可修复，不形成永久种姓。
- **工程**：actor 模型（每主体=独立状态 actor，监督树容错，Erlang/Akka 理念，Rust 可用 actix/ractor 等）；能力路由+服务发现；共享态用 CRDT/event-sourcing；编排器只路由不独裁。

### 横切：可观测 / 可回滚 / 可持续评估
- 每个结论可回溯：候选集、批评记录、选择理由、抑制是否触发（全程留痕）。
- 模型、记忆、宪法全部版本化、可回滚（"可逆退出"）。
- 评估 harness 做能力与安全的持续回归，防退化。

## 3. 核心接口骨架（Rust，可直接开工）

```rust
// 一条经结构化校验、可进入全局工作空间的候选（假设/解/动作）
struct Candidate { id: Id, kind: Kind, content: Content,
    evidence: Vec<Evidence>,   // 事实材料（必填）
    counter:  Vec<Content>,    // 反方意见（强制，防极化/谄媚）
    source:   Source,          // 来源/利益标注（上行保真）
    confidence: f32, scope: Scope }

trait Specialist: Send + Sync {                 // 分布式认知器官（异构/可插拔/稀疏激活）
    fn can_handle(&self, ctx:&Context)->bool;
    async fn perceive(&self, obs:&Obs, ws:&dyn Blackboard)->Vec<Candidate>;
}
trait Blackboard: Send + Sync {                 // 全局工作空间：只结构化/广播/留痕，不决策
    async fn post(&self, c:Candidate)->Result<(),Reject>;  // 含"正式门槛"校验
    fn broadcast_focus(&self)->Focus;                      // 有限容量点火广播
    fn audit(&self)->&AppendOnlyLog;                       // 程序事实不可篡改
}
trait Evolver {                                 // 达尔文层：变异—批评—选择—淘汰
    async fn diversify(&self,f:&Focus)->Vec<Candidate>;
    async fn critique(&self,p:&[Candidate])->Vec<Scored>;  // 红队/工具核验，与生成器不同源
    fn select(&self,s:Vec<Scored>)->Candidate;
}
trait Inhibition { fn veto(&self,a:&Action,c:&Context)->Veto; } // 确定性刹车，不可被学习覆盖
trait Executive { async fn decide(&self,ws:&dyn Blackboard,e:&dyn Evolver,b:Budget)->Action; }
trait Memory {
    fn put(&self,l:Layer,x:MemItem,ttl:Duration); fn recall(&self,q:&Query)->Vec<MemItem>;
    async fn consolidate(&mut self);           // 睡眠：情景→语义 + 遗忘/修剪
}
struct Budget{ wallclock:Ms, tokens:u32, population:u32, depth:u32 }
trait Metabolism { fn allocate(&self,difficulty:f32,stake:Stake)->Budget; } // 按需供血

struct AgentCore { /* 注入上述全部组件 */ }
impl AgentCore {
    async fn step(&mut self)->Result<()> {
        let obs   = self.env.observe().await?;                 // ① 感知（原始流不可改）
        let hyps  = self.specialists_parallel(&obs).await;     // ② 分布式认知
        self.ws.post_all(hyps).await?;                         // ③ 上黑板（门槛/反方/来源）
        let focus = self.ws.broadcast_focus();                 // ④ 注意聚焦广播
        let bud   = self.metab.allocate(focus.difficulty,focus.stake); // ⑤ 按需供血
        let mut act = self.exec.decide(&self.ws,&self.evolver,bud).await?; // ⑥ 竞争+收敛
        if let Veto::Block(r)=self.veto.veto(&act,&focus.ctx){ act=self.exec.fallback(r).await?; } // ⑦ 抑制兜底
        let out = self.env.act(act).await?;                    // ⑧ 具身行动
        self.learn_from(&out).await;                           // ⑨ 再感知/误差回灌
        Ok(())
    }
}
// L7：每个 AgentCore 是一个 actor，任务导向临时组队、完事即散、共享知识公地
```

## 4. 与当前单体 LLM 路线的本质区别

| 维度 | 单体大模型路线 | SoCA 认知联合体 |
|---|---|---|
| 智能来源 | 规模涌现（赌参数长出能力） | 架构闭环（规模只是旋钮） |
| 结构 | 一组权重包打一切 | 异构专门单元 + 黑板 + 进化 + 抑制 |
| 事实 | 参数记忆，易幻觉 | 强制证据/反方/工具核验，上行保真 |
| 纠错 | 单次前向，开环 | 内部达尔文竞争 + 具身再感知闭环 |
| 安全 | 对齐外挂、可被数据污染 | 确定性抑制层外置、不可被学习覆盖 |
| 记忆 | 权重僵硬 + 上下文易失 | 四层记忆 + 主动巩固/遗忘 |
| 算力 | 请求均摊 | 按难度/利害动态供血 |
| 扩展 | 把一个脑做到无限大 | 小主体闭环 → 拧规模 → 组成社会 |

## 5. 可工程化路线（先做"数字苍蝇"，每阶段都可跑、可验证）

### 阶段 0｜数字苍蝇 v0（1–2 周，零训练，验证闭环骨架）
- 不训模型，全部"认知单元"用现成 LLM API 的不同角色充当；选一个极简环境（gridworld / 文本世界 / 一个真实小任务，如自动整理目录）。
- 实现：内存黑板+事件日志、3 个 specialist（观察、反方、批评）、Executive 状态机、**硬编码规则 guardrail**、working memory。
- 验收：能连续自主跑"观察→多候选→自我批评→选择→动作→看结果→更新"，且 guardrail 能稳定否决越界动作。**目标不是聪明，是闭环通。**
- 技术栈：Python 快速原型 或 Rust（ractor/tokio + LLM API）。

### 阶段 1｜完整单主体内核（数字猫狗，1–2 月）
- 世界模型与预测误差驱动；四层记忆（向量库+TTL 遗忘+睡眠巩固）；代谢调度（按难度分预算）；好奇心内在动机；工具调用（MCP）；各 specialist 换开源小模型本地跑、gating 稀疏激活。

### 阶段 2｜多主体社会
- 单主体 actor 化 → 多主体、任务招标临时组队、共享知识公地、社会层防级联、可修复声誉。

### 阶段 3｜学习与进化
- 用积累经验微调/替换专门小模型；达尔文层接 self-play 与开放式进化；世界模型从经验中学习（语义记忆固化）。

### 阶段 4｜最后才拧规模旋钮
- 架构冻结后再加大模型、加多主体、加长记忆、加宽广播——架构不定，加规模只会放大缺陷。

## 6. 现成积木 / 自研护城河 / 开放难题（诚实清单）

**现成可直接用**：LLM 充当 specialist 与 reasoner；向量库/图库；MCP 工具与协作协议；actor 框架；规则引擎做抑制；pymdp 等主动推断库；blackboard/GWT、多智能体辩论、best-of-N、self-play 均为成熟模式。

**真正要自研的核心（=研究点/护城河，每个都能独立实验）**：
1. 黑板的"正式门槛 + 点火广播"调度算法（显著度模型与有限容量分配）；
2. 达尔文层"多样性—收敛"平衡与停止准则；
3. 分层记忆的巩固/遗忘策略（何时把经历变知识、何时忘、如何 unlearning）；
4. 代谢调度控制器（难度/利害 → 思考预算）；
5. 预测误差作为统一驱动信号的落地；
6. 社会层防级联与异见保留机制。

**开放难题（不吹，明确标注）**：
- 现象意识（hard problem）：工程上先实现"功能意识/access consciousness"，是否产生主观体验不可证，不阻塞工程；
- 内在动机的对齐风险：自驱目标可能漂移，故宪法层必须外置、不可学、人类保留否决；
- 长期记忆一致性与漂移、多主体社会的算力成本、安全的形式化保证，仍是待解问题。

## 7. 与社会治理设计的同构（双向印证）
同一抽象结构在三种基质上复现：神经元社会（脑）、公民社会（人民事务组织+国家）、硅基社会（本架构）。
- 黑板=公共议题反馈平台；specialist=人民事务组织；达尔文层=多方对质与事实核验；
- 确定性抑制层=法治/硬规则，优先级高于"人数/概率"；代谢调度=资源按需配置；
- 非对称记忆=对公权力长记忆、对公民短记忆；L7 临时组队=事务性、无权力结构、完事即散。
**脑给架构提供存在性证明，AI 是最快的可实验平台（几小时跑完组织原则对比），社会设计则反哺安全与伦理约束。**
